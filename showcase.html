Authentication & Token Defense

Cryptographic isolation per connected client

  • ✓ SHA-256 Hashes Only: Plaintext tokens (swt_...) are shown once and never stored unhashed in MySQL.
  • ✓ Per-IP Rate Limiting: 100 failed auth attempts in 5 minutes triggers automatic HTTP 429 throttling with Retry-After.
  • ✓ Instant Revocation: Revoke any token individually or terminate all active agent sessions in one click.
  • ✓ Privacy-First Activity Log: Keeps track of timestamps and tool results without logging arguments or secrets.
🛡️

Path Guard & Filesystem Jail

Strict containment within permitted directories

  • ✓ Filesystem Jail: Confinable to WordPress root (ABSPATH) or strictly wp-content.
  • ✓ Protected Files Shield: Blocks reading, writing, or deleting critical files like wp-config.php or .htaccess.
  • ✓ Symlink & Traversal Immunity: Resolves real paths, rejecting directory traversal attempts (../) and null bytes.
  • ✓ Windows & NTFS Sanitization: Blocks Windows trailing dots/spaces and alternate data stream injections (::$DATA).
⚡

Crash-Safe PHP Sandbox

Isolated execution with automated recovery

  • ✓ Sandbox Isolation: Agent-written PHP is restricted by default to wp-content/sitewright-sandbox/.
  • ✓ Automatic Safe Mode: If agent code causes a fatal PHP error, sandbox loader pauses execution so your admin remains accessible.
  • ✓ Error Capture: Exact PHP error stack trace and offending file name are logged directly in the Diagnostics panel.
🗄️

SQL Guard & Database Shield

Safe querying with hard limits

  • ✓ Single-Statement Enforcement: Multiple queries separated by semicolons are strictly rejected.
  • ✓ System Schema Refusal: Queries attempting to query mysql, information_schema, or performance_schema are blocked.
  • ✓ Server File I/O Block: Blocks dangerous MySQL file queries (INTO OUTFILE, LOAD_FILE(), LOAD DATA).

Architecture & Data Flow

How MCP clients communicate with WordPress securely over Streamable HTTP.

1
AI Coding Agent

Claude Code, Cursor, Windsurf, or Antigravity executes an instruction and decides to call an MCP tool.

2
Streamable HTTP

Standard JSON-RPC 2.0 request sent to /ai-connect/v1/mcp with Bearer Token in Authorization header.

3
Security Perimeter

Verified by SHA-256 token validator, IP rate limiter, Master switch, Path Guard, and SQL Guard.

4
WordPress Execution

Direct access to $wpdb, filesystem, options, content, or queued into async background jobs engine.
